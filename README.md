# E-Commerce Order Discount & Delivery System

## About the Project
This project calculates the discount, delivery charges, and final payable amount for an e-commerce order.

## Features
- Accepts Customer ID and Order Amount
- Supports Premium and Regular customers
- Calculates discounts based on customer category
- Provides an additional discount for orders above ₹5,000
- Calculates delivery charges based on location
- Displays the final payable amount and order summary

## Technologies Used
- JavaScript
- Node.js

## How to Run
1. Install Node.js.
2. Open the project folder in the terminal.
3. Run the following command:

   node Ecommerce.js
